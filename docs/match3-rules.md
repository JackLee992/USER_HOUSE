# 宝石消消乐：模式、特效与本局奖励

本模块是原创三消实现。参考了[宾果消消消官方入驻介绍](https://www.taptap.cn/app/11983)所描述的传统三消、多种棋子和组合技方向，以及[开发者的 App Store 页面](https://apps.apple.com/cn/app/宾果消消消/id897447840)中的关卡与收集玩法。上述官方页面没有公开完整的特效判定表；下面的精确范围、方向、分值和关卡曲线是本项目明确制定的规则，不宣称完整移植该商业游戏。没有使用其角色、图标、音效、关卡或其他商业素材。

## 制造与触发

棋盘保持 8 × 8、六种颜色与形状。点击相邻两颗或滑动交换；普通交换必须产生三连，无效交换退回且不扣步。一次有效交换扣一步，后续所有掉落连锁不再扣步。

| 图案 | 生成棋子 | 后续触发效果 |
| --- | --- | --- |
| 横向四连 | ↔ 横向直线 | 清除整行 |
| 纵向四连 | ↕ 纵向直线 | 清除整列 |
| 一条直线五颗及以上 | ◉ 彩虹 | 与任意普通棋子交换，清除其全部同色棋子 |
| L、T、十字交叉 | ✹ 爆弹 | 清除自身周围 3 × 3 区域，边缘截断 |

匹配组优先生成彩虹，其次爆弹，再次直线。每个连通匹配组生成一颗；优先落在交换目的格，其次来源格，再次该组普通棋子处。特殊棋子本身被三连或其他特效打中时触发；不覆盖已有特效来制造新特效。新造的特效在本轮存活并随重力下落，从下一轮起可以触发。彩虹不参与普通同色三连。

## 直接交换特效

两颗相邻特殊棋子不需要再凑三连即可组合。组合爆破会继续触发范围内的其他特效，每颗特效每轮最多触发一次、每个位置最多计分和计入收集一次。

| 交换组合 | 效果 |
| --- | --- |
| 直线 + 直线 | 目的格十字清除，并触发两颗本身的行/列效果 |
| 直线 + 爆弹 | 以目的格为中心，清除三整行与三整列 |
| 爆弹 + 爆弹 | 目的格为中心清除 5 × 5，边缘截断 |
| 彩虹 + 普通 | 清除普通棋子的全部同色棋子 |
| 彩虹 + 直线/爆弹 | 全部目标同色棋子转成该类特效并立即触发；直线按位置交替横/纵 |
| 彩虹 + 彩虹 | 清除整个棋盘 |

彩虹被范围效果打中时，选择当前棋盘数量最多的一种普通颜色清除；数量相同取颜色编号最小者。特殊棋子加普通棋子的交换（彩虹除外）仍需形成匹配。

## 分数、关卡与保存

每颗消除计 10 分，四连奖励 20、五连及以上奖励 50；连锁轮次倍率最高 ×5。制造新特效的匹配按完整匹配数量计基础分，但留下的新特效不计入已收集数量。

顶部“玩法”下拉框提供三种模式。选择后还需点击“保存并切换”，取消不会改变状态。每种模式保存独立棋盘、关卡、分数、步数和目标；随时切回继续，共享同一本局的星星和金币。

| 模式 | 目标与推进 |
| --- | --- |
| 经典闯关 | 第一关仅分数；第二关起一种颜色收集，第四关起第二种。分数和全部收集目标都满足才过关，随后进入新棋盘。 |
| 破冰挑战 | 同时达到分数与清空固定格上的冰层。第一关中央 16 格一层冰；第二关扩展部分外圈；第三关起部分中央格变为双层冰；第四关起覆盖中央 6 × 6。过关进入新棋盘。 |
| 无限休闲 | 无步数限制，不因步数失败。每累计 1000 分完成一个里程，继续使用当前棋盘和已有特效；超额分数带入下一里程。 |

经典与破冰的步数从 28 逐渐下降，最低 18；最后一步达成全部目标仍然过关。步数耗尽后保存状态并显示“重试本关”，不会自动清除星币或结算。重试清空当前关的分数、目标进度和已用道具计数，重新生成棋盘和冰层；此前已花费的金币不退还，已获得的奖励与其他模式进度保留。

冰层属于位置，不随宝石下落。匹配或特效命中该位置每波消去一层；新制造特效的匹配位置也计入破冰。一波中重复命中不叠加，下一波连锁可继续消去第二层。无路可走时自动重排，不扣步、不消冰，保留已获得特效的类型和数量。

## 星星、金币与道具

星币是本地本局玩法奖励，无付费和联网兑换。开局提供 30 金币；不同模式共享钱包。

- 经典、破冰过关按剩余步数评星：至少初始步数的 1/3 为 3 星，至少 1/6 为 2 星，其余为 1 星。分别获得 50、40、30 金币。
- 无限模式每 1000 分给 1 星、20 金币；一次连锁跨过多个里程会一并发奖。
- 每个模式的每一关或里程只发一次奖励，发奖标记与钱包在同一个稳定存档中保存；重新载入已达标关卡不会再次发奖。
- 小锤消耗 20 金币：先点击“小锤”进入选格状态，再点目标格敲碎；再次点“小锤”可取消且不扣币。命中特效会触发该特效和连锁，可破冰，不扣步。
- 重排消耗 15 金币：确认后生成无现成匹配且有合法交换的新棋盘，保留特效类型/数量、冰层、分数、收集目标和剩余步数，不赠送消除分数。

顶部持续展示本局星币，通关提示显示本次奖励。只有敲锤动画全部结束才提交棋盘和扣币，因此动画中退出会恢复敲锤前的完整状态。

“结束本局”需要二次确认并调用已有成绩记录入口，记录当前模式的分数、关卡以及本局星币元数据。该操作与外层“重开”都会重置全部模式进度和本局星币；确认框中明确提示这一结果。要稍后继续，应使用外层返回，保留整份存档。

## 存档与生命周期

存档仍为 8 × 8 数字棋盘：0–5 普通，6–11 横线，12–17 纵线，18–23 爆弹，24–29 彩虹。当前版本为 `rulesVersion:3`，包含 `mode`、`goals`、`collected`、固定格 `ice[64]`、`turnsUsed`、`toolsUsed`、共享 `wallet { coins, stars, claimed }`、其他模式的 `modeStates` 和最近 `lastReward`。`claimed` 保存各模式已发奖关卡的最高编号。

无版本旧存档保留棋盘、分数、步数，当前关继续只要求分数，下一关进入新目标规则；v2 存档保留特效与当前收集目标。缺失钱包的旧存档获得初始 30 金币。三个模式和钱包始终通过同一份 `env.save` 保存，没有额外的 localStorage 钱包。

动画过程中只保存本次交换或敲锤前的完整稳定状态；全部连锁结束才提交新状态和奖励。暂停期间停止动画进度，不接受模式确认、道具或结算操作。销毁会取消 RAF 和所有事件监听，不在销毁后写存档。
