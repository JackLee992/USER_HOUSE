# 空当接龙：安全归档与双击归位

“安全归档”按钮可一次收取全部当前安全牌。“随步归档：开/关”控制每次有效移动后是否自动收牌；默认关闭，旧存档也保持关闭，避免恢复牌局时未经操作就改变局面。打开开关仅设置后续移动行为，不立即收牌。

桌面双击，或手机在 400 毫秒内快速连点同一张牌，可将该牌移到同花色收牌区。只接受空当中的牌或牌列最下端完全露出的单张牌，严格遵守同花色 A → K；不会跳过遮住它的牌，也不会自动重排各列。双击是玩家明确指定的合法移动，因此不受下述保守安全门槛限制。无效双击不计步、不增加撤回记录，也不会代替玩家移动其他已选中的牌。

普通单击仍是“选牌 → 点目标”。空当、空列及收牌区即时响应；当目标本身也是一张可双击的牌时，最多等待 400 毫秒以区分单击移动和双击归位。键盘激活保持普通选牌／移动行为。控制器按牌的身份及所在位置识别连续点击，选择后的 DOM 重绘不会破坏手机双触识别；同一次手势尾随的原生 `dblclick` 不会继续收取新露出的下一张牌。

安全规则：

- 只处理空当中的牌或牌列最下端完全露出的一张。
- 收牌区必须仍按同花色 A → K 顺序接收。
- A、2 在同花色收牌区可接收时直接归档。
- 3 及以上，需要两种异色收牌区都达到低一阶。例如 ♣4 必须等待 ♥3 与 ♦3 均已归档。
- 反复检查新露出的牌，直到没有安全牌。手动收牌仍遵循原有合法性，不强制采用自动收牌的保守条件。

一次“一键归档”整体算一步；没有可收牌时不计步、不增加撤回记录。玩家移动后触发的全部自动归档与该次移动合为一步，点一次撤回即可恢复整步。撤回不改变用户当前选择的自动开关。自动收完 52 张时结算一次；结束或销毁后不会再次保存或结算。

存档保持原来的 columns/freecells/foundations/history 结构，仅可选增加布尔字段 `autoHome`，不需要 runtime 存档结构变更。历史记录最多保留 100 步。

运行规则和控制器回归：

```sh
node --test tests/freecell*.test.mjs
```

31 条规则及控制器测试覆盖安全门槛、连续归档、空当收牌、无操作不计步、开关、整体撤回、旧存档与 JSON 恢复、双击／双触、DOM 重绘后的旧事件、已有选牌时的双击、连续选择不同牌、键盘与慢速点击、暂停／撤回／销毁时取消待执行移动，以及完成后的单次结算。
