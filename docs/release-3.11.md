# 玩伴小屋 3.11.0

此版本从 `JackLee992/USER_HOUSE_ANDROID` 的同一游戏源码提交同步生成，完整提交记录见仓库根目录 `release-source.json`。酒馆插件只包含 Web 游戏、共享运行层、五种语言和游戏美术，不包含 Android/iOS 工程与设备测试截图。

## 本次同步

- 贪吃蛇 1.2.1：经典方格新增休闲、经典、极速三档速度；默认速度降至 160ms，每次触控支持三步合法转向预输入；竞技场修复吃食物不增长，并提高初速和加速响应。
- 祖玛 1.1.3：全屏神庙关卡、WebGL 动效、开局球链和骷髅入场动画。
- 俄罗斯方块 1.1.2：全屏沉浸、AI/马拉松/冲刺玩法、经典十字键和长按连续输入。
- 数独 1.1.0：笔记、自动候选、撤销/重做、逻辑提示和四档新题。
- 泡泡龙 1.0.3：简化纯色圆球、完整边缘与按时间推进的流畅动画。
- 空当接龙 1.0.1：全屏、安全自动归档、双点归档和整步撤销。

插件继续使用原存档键和 `auto_update`。已安装 `https://github.com/JackLee992/USER_HOUSE` 的用户可直接在 SillyTavern 扩展管理中点击更新，然后刷新页面，不需要卸载。
