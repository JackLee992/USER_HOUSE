# 经典小游戏与 Via 动画修复规格

用户已于本会话确认按经典版本核心玩法实现。工作分支仅属于 JackLee992/USER_HOUSE fork。

## 泡泡龙
保留原有规则、分值、碰撞步进和外观。掉落速度按真实时间推进，60 Hz 下保持原速度，10/15/30/120 Hz 结果一致。暂停冻结运动和爆裂，重开或退出取消动画、延迟结算及 resize 监听，返回前台不追赶后台时间。真实 Via Android 测试与确定性低帧率回归均保存证据。模拟器不能代替用户原手机的功耗/浏览器配置复现。

## 空当接龙
52 张唯一牌，8 列（前4列7张、后4列6张）、4空位、4花色回收区。列内红黑交替降序，回收区同花色 A 至 K，空列可放任意牌。按可用空位/空列计算合法连续序列移动容量，目标空列不计入容量。点击源与目标移动，支持双击回收、撤销、提示、重开；52张全部回收胜利。经典绿色桌面、清晰纸牌，窄屏保持8列并确保可点击。存档保留牌局、步数、计分。

## 三维弹球（按用户后续要求修订）
用户明确否定简化矢量球台，要求经典 Space Cadet 布局与玩法。3.9 使用完整 MIT 引擎及 CC0 Open Cadet 数据，保留坡道、虫洞、超空间、任务、燃料、军衔和全部碰撞装配；重绘静态球台，动态挡板、灯光与球仍由引擎驱动。触屏双挡板、长按蓄力发射；使用实际 Android Via 测试。保存完整同页暂停实例，跨刷新仅恢复新球检查点并说明边界。

## 消消乐
8×8 棋盘，6种可用颜色/形状，交换相邻两格形成横竖3连及以上；无效交换还原且不扣步数。消除计分、重力落下、补新与连续连锁，4连/5连奖励，关卡步数与目标分逐级增加。开局无匹配且至少一个合法走法，无步可走重排，达到目标进入下一关、步数用尽失败。触控点击/交换，短时间动画按时长，暂停、取消与存档一致。

## 集成和验收
每款新游戏独立 ES 模块，采用现有 createXGame(env,state) 接口；env 为 root/document/window/save/clear/setScore/finish/speak/toast/isPaused/isActive。返回 destroy/save/getState。规则函数可通过 node:test 验证。运行时登记游戏名称、规则、可继续进度和启动函数，沿用主题变量、返回/暂停/重开/记录。配套中文说明。用户后续已授权直接合并到 fork 的 main，让安装者不必区分分支。
